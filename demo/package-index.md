# openindex entry — widget

An index of published packages, maintained separately from the projects it
lists. Entries are written from what a project published, and each one records
when the index first saw it.

## widget

| Field | Value |
| --- | --- |
| Latest version | 2.0 |
| First seen | 2026-09-14 |
| Declared licence | Apache-2.0 |
| Changelog entry for 2.0 | recorded 2026-09-14 |
| Previous version | 1.9 (2026-06-02) |

The 2.0 entry carries a changelog recorded on 2026-09-14: the audit log was
added and the legacy exporter was removed.

The index does not verify the claims a project makes about itself. It records
what was published, and when this index first saw it.
